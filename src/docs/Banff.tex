    \begin{itemize}[leftmargin=4mm, labelsep=2mm, topsep=1mm, itemsep=1mm, parsep=0pt]
        \item \textbf{Trash Disposal:} Kyoto has very few public trash cans. Carry a small plastic bag to store trash until you return to the hotel.
